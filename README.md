# 📖 Бот для продажи книги за Telegram Stars

Поток покупателя: `/start` → выбор языка (RU / TJ) → продающий текст → бесплатная глава 1 → оплата **199 ⭐** → бот присылает HTML-книгу на выбранном языке.

## Что в папке

| Файл | Зачем |
|---|---|
| `bot.py` | Вся логика бота |
| `texts.py` | Тексты: продажа, кнопки, бесплатная глава (меняй здесь) |
| `books/kniga_ru.html`, `books/kniga_tj.html` | Книги, которые получает покупатель |
| `requirements.txt`, `railway.json`, `Procfile`, `.python-version` | Настройки запуска для Railway |
| `.env.example` | Пример переменных (сам `.env` в GitHub не грузим!) |

---

## Шаг 1. Создай бота в Telegram

1. Открой **@BotFather** → `/newbot`.
2. Придумай имя и username (заканчивается на `bot`).
3. Скопируй **токен** (длинная строка вида `123456:ABC...`). Никому его не показывай.
4. По желанию: `/setuserpic` (аватарка), `/setdescription` (описание), `/setabouttext`.

Платёжный провайдер подключать **не нужно**: Telegram Stars работают сразу.

## Шаг 2. Узнай свой Telegram ID

Открой **@userinfobot** → `/start` → скопируй число `Id`. Это твой `ADMIN_ID`: сюда бот будет присылать уведомления о покупках.

## Шаг 3. Загрузи проект на GitHub

> ⚠️ Репозиторий делай **Private** (приватным), иначе любой сможет скачать твои книги бесплатно.

1. Зайди на github.com → **Sign up** (или Login).
2. Нажми **+** (справа сверху) → **New repository**.
3. Название, например, `kniga-bot`. Выбери **Private**. Нажми **Create repository**.
4. На странице репозитория нажми **uploading an existing file**.
5. Распакуй архив на компьютере и **перетащи всё содержимое папки** (включая папку `books`) в окно браузера.
   Проверь, что `bot.py` лежит в корне, а не внутри вложенной папки.
6. Внизу нажми **Commit changes**.

## Шаг 4. Запусти на Railway

1. Зайди на **railway.com** → **Login** → **Login with GitHub**.
2. **New Project** → **Deploy from GitHub repo** → выбери `kniga-bot`
   (если репозитория нет в списке: **Configure GitHub App** и дай доступ к нему).
3. Открой созданный сервис → вкладка **Variables** → добавь переменные:

| Имя | Значение |
|---|---|
| `BOT_TOKEN` | токен от BotFather |
| `PRICE_STARS` | `199` |
| `ADMIN_ID` | твой Telegram ID из шага 2 |
| `SUPPORT_CONTACT` | твой @username для связи по оплатам |
| `DB_PATH` | `/data/bot.db` |
| `STARS_URL` | *(необязательно)* ссылка, где покупают звёзды дешевле / из России. По умолчанию уже стоит твоя: `https://t.me/suastarsbot?start=user-6147195726` |

4. **Чтобы история покупок не пропадала при перезапусках**, добавь диск: в проекте нажми **+ New** → **Volume** → подключи к сервису, **Mount path**: `/data`.
5. Дождись деплоя. Во вкладке **Deployments → View logs** должна появиться строка `Бот запущен: @твой_бот`.
6. Домен (Networking) создавать не нужно: бот работает через polling.

## Шаг 5. Проверь, что всё работает

1. Временно поставь `PRICE_STARS` = `1`, дождись передеплоя.
2. Открой бота → `/start` → выбери язык → нажми «Читать главу» → «Купить».
3. Оплати 1 ⭐ (нужны звёзды на твоём аккаунте). Должен прийти файл книги.
4. Тебе придёт уведомление с `charge_id`. Верни звёзды себе командой:
   `/refund <charge_id>`
5. Поставь `PRICE_STARS` обратно на `199`.

## Кнопка «Купить звёзды дешевле»

В боте есть кнопка со ссылкой на сервис покупки звёзд (для тех, у кого нет звёзд или кто живёт в России). Она показывается под продающим текстом, после бесплатной главы и рядом со счётом на оплату. Ссылку можно поменять в переменной `STARS_URL` на Railway или в `bot.py`, текст кнопки и подсказки правится в `texts.py` (`btn_stars`, `stars_hint`).

## Команды бота

| Команда | Кто | Что делает |
|---|---|---|
| `/start` | все | начало, выбор языка |
| `/paysupport` | все | поддержка по оплате (**обязательна** для ботов с платежами) |
| `/stats` | админ | пользователи, покупки, сумма звёзд |
| `/refund <charge_id>` | админ | вернуть звёзды покупателю |

## Как менять тексты и обновлять книгу

- Тексты: редактируй `texts.py` прямо на GitHub (иконка карандаша) → **Commit**. Railway сам передеплоит бота.
- Книга: замени файлы в папке `books/` (Add file → Upload files) → **Commit**.

## Вывод заработанных звёзд

Звёзды копятся на балансе бота. Вывод идёт через **Fragment** (в TON). Актуальные условия (минимальная сумма, срок удержания, комиссии) смотри в документации Telegram Stars и в настройках бота у @BotFather, они могут меняться.

## Стоимость Railway

Railway даёт пробный кредит, потом нужен платный план. Актуальные цены: railway.com/pricing. Для одного бота расход небольшой.

## Частые проблемы

- **В логах `BOT_TOKEN не задана`**: не добавлена переменная в Variables.
- **`Не найден файл книги`**: папка `books` загружена не в корень репозитория.
- **Бот молчит**: проверь токен и то, что в логах нет ошибок; убедись, что бот не запущен параллельно на компьютере (два запуска с одним токеном конфликтуют).
- **Файл не открывается красиво**: открывать в браузере (Chrome/Safari). Нужен интернет для шрифтов.

## Важно про защиту от копирования

Бот отправляет файл с `protect_content=True`: Telegram блокирует пересылку и сохранение из чата. Но человек всё равно может скопировать файл со своего устройства, полностью защититься от этого нельзя.
